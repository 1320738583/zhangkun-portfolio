# 张坤个人作品集

基于 React + Vite 的单页作品集，面向招聘方，采用暗色影像风格。内容来自用户提供的两份简历和 `E:\坤\作品集`。

## 本地运行

需要 Node.js 20.19+ 或 22.12+ 与 pnpm。

```sh
pnpm install
pnpm dev
```

打开终端显示的本地地址（默认 `http://127.0.0.1:5173/`）。保持启动窗口运行，即可持续预览修改。

```sh
pnpm build
pnpm preview
```

构建产物位于 `dist`。标准 `index.html` 通过 HTTP 服务预览；另提供可双击打开的 `dist/作品集预览.html`，用于本地浏览器连接服务异常时查看。移动这个预览文件时，请连同整个 `dist` 文件夹一起移动，以保留视频和图片。

## 内容与素材

- `src/main.jsx`：个人介绍、经历、联系方式、项目资料及页面交互。视频与设计项目分别位于顶部的 `videoProjects` 和 `designProjects` 数组。
- `src/styles.css`：配色、1700px 最大版心、PC / 平板 / 手机布局。
- `src/Grainient.jsx`：头图下方的深灰动态颗粒渐变背景，使用 `ogl` 渲染，并在离屏、页面隐藏或系统减少动态效果时暂停动画。
- `public/media`：已生成的网页素材副本，网站运行时不依赖 E 盘原文件。原始作品未被修改。
- `hero.mp4`：从《西藏分公司》提取的8秒静音背景。浏览器禁止自动播放或用户启用减少动态效果时，可显示封面并手动播放。
- 设计类项目采用真实设计稿预览；书籍未选用封面明确标注为探索稿。

作品区分为“视频剪辑”和“视觉设计”两个专区：视频区包含12条作品，设计区包含4组共10份素材。视频仅在打开弹窗后加载；设计弹窗用于切换和放大设计稿。手机端提供折叠导航，弹窗支持关闭按钮和 Esc，邮箱提供复制按钮，电话和邮箱使用系统链接。

手机端的视频与设计作品采用横向滑动卡片，支持触摸滚动、逐卡吸附和当前位置计数；桌面端继续使用多列网格。

导航沿用首版横向布局；页面进入第二屏后固定在顶部并显示磨砂玻璃背景。“精选作品”下拉菜单可直接进入视频剪辑或视觉设计专区，主要按钮均提供鼠标悬浮换色反馈。

五日浏览量15,275来自简历中的《宏业建设31岁生日》，并非其他精选作品的数据。AI能力仅依据简历工具经验描述，未将现有作品标记为AI生成。

`scripts` 中的媒体脚本是本机素材准备工具，使用系统提供的 Python 运行时以及 Pillow、pypdfium2、imageio-ffmpeg。已生成的素材可以直接使用，无需重新运行脚本。

生产构建同时生成标准网页和可双击打开的离线预览；临时公网预览地址以最近一次 Cloudflare Tunnel 启动结果为准。

## 首版验证

发布前应检查390、768、1440、1920像素宽度，并验证12条视频、10份设计素材、项目弹窗、设计稿切换、手机导航与Esc关闭。
